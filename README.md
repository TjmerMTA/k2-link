# k2-link

Постійна адреса-перенаправлення. Сама система працює на робочій машині за
тимчасовою адресою тунелю, яка змінюється при кожному запуску; ця сторінка
лишається незмінною і веде на актуальну.

Адресу оновлює команда `npm run k2:tunnel` у проєкті системи.

- `/` — головна форма
- `/#admin` — адмінка
- `/#tck`, `/#temp`, `/#hot` — інші форми
